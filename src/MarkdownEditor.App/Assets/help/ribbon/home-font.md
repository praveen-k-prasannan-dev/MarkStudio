# Home Tab — Font

| Button | Shortcut | Markdown produced |
|--------|----------|--------------------|
| **Bold** | `Ctrl+B` | `**bold**` |
| *Italic* | `Ctrl+I` | `*italic*` |
| ~~Strikethrough~~ | `Ctrl+Shift+X` | `~~strikethrough~~` |
| `Inline code` | `Ctrl+Shift+C` | `` `code` `` |
| Highlight | `Ctrl+Shift+H` | `==highlight==` |

Every one of these is a **toggle**, exactly like Word:

- Select some text and click Bold (or press `Ctrl+B`) — it becomes bold.
- Select that same bold text and click Bold again — the `**`/`**` markers are removed.
- With nothing selected, clicking inserts the marker pair and places your cursor between them, ready to type.

These also work from the [right-click context menu](../context-menu.md) (Bold and Italic are there directly) and from the [Command Palette](../command-palette.md) (all five are searchable by name).
