# View Tab — Layout & Preview

| Group | Controls |
|-------|----------|
| Layout | **Split** (default) / **Editor only** / **Preview only** |
| Preview | Sync scrolling on/off · **Theme**: Light / Dark / Custom… |
| Editor font | A− / A+ text size |

## Layout

- **Split** shows the editor and preview side by side, with a draggable splitter between them.
- **Editor only** and **Preview only** hide the other pane, useful on a smaller window or when you just want to read.
- **Sync scrolling** keeps the preview's scroll position roughly aligned with the editor's as you scroll or type.

## Preview theme

- **Light** and **Dark** are the two built-in themes.
- **Custom…** opens a file picker for any `.css` file of your own — your choice is remembered across restarts.
- This Help window also follows whichever of Light/Dark you last picked.
