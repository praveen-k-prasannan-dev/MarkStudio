# The Table Tab

This tab only appears in the ribbon while your caret is inside a table — like Word's Table Tools.

| Group | Controls |
|-------|----------|
| Rows | Insert Row Above · Insert Row Below · Delete Row |
| Columns | Insert Column Left · Insert Column Right · Delete Column |

All six are also available from the [right-click menu](../context-menu.md)'s **Table** submenu, and from the [Command Palette](../command-palette.md) whenever your caret happens to be inside a table.

See [Insert Tab — Tables](insert-tables.md) for creating a table in the first place, and `Tab`/`Shift+Tab` for moving between cells.
