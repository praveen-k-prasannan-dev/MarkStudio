# Insert Tab — Links & Images

| Button | Shortcut | Markdown produced |
|--------|----------|--------------------|
| 🔗 Link | `Ctrl+K` | `[text](url)` |
| 🖼 Image | `Ctrl+Shift+I` | `![alt](path)` |

- **Link** opens a small dialog for the link text and URL.
- **Image** opens a file browser; the chosen image's path is made **relative to your document** automatically, so the link keeps working if you move the whole folder.
- You can also just **drag an image file** onto the window — it's copied into an `assets/` folder next to your document and inserted for you.

See the [Links & Images reference](../markdown-reference/links-images.md) for the raw syntax, including reference-style links and image titles.
