# Insert Tab — Tables

- **Table ▾** opens a Word-style hover grid picker — move your mouse over the grid to choose how many rows/columns you want, then click to insert.
- **Insert Table…** opens a dialog where you type the exact number of rows and columns instead.

Once your caret is inside a table, a contextual **Table** tab appears in the ribbon (like Word's Table Tools) — see [The Table Tab](table-tab.md) for row/column insert and delete.

## Interactive editing

- **`Tab`** jumps to the next cell, selecting its contents so you can type to replace it (like Excel). Tabbing past the last cell of the last row automatically adds a new row and moves into it.
- **`Shift+Tab`** jumps to the previous cell.
- The [right-click menu](../context-menu.md) also offers the same row/column commands while your caret is inside a table.

For the raw Markdown syntax tables produce (pipes, alignment, header separators), see the [Tables reference](../markdown-reference/tables.md).
