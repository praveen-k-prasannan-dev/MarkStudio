# View Tab — Panels

| Button | What it shows |
|--------|----------------|
| ☰ Outline | A tree of every heading in the document — click one to jump straight to it |
| 🗀 Workspace | A folder file tree with instant cross-file search — see [Workspace Mode](../workspace-mode.md) |

Both panels appear as a sidebar on the left of the editor and can be toggled independently. Opening one doesn't close the other, though showing both at once on a narrow window will feel cramped — resize as needed.
