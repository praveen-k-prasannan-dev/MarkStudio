# Insert Tab — Blocks

| Button | Shortcut | What it does |
|--------|----------|---------------|
| Code block ▾ | `Ctrl+Shift+K` | Inserts a fenced code block; the dropdown lets you pick a language (`csharp`, `python`, `javascript`, `typescript`, `sql`, `bash`, `xml`, `html`, `css`, `yaml`, `json`, or none) for syntax highlighting in the preview |
| Horizontal rule | — | Inserts `---` |
| Footnote | — | Inserts a footnote reference and its definition |

Typing the word **`code`** and pressing `Tab` does the same thing as a snippet — see [Templates & Snippets](../templates-snippets.md).

See the [Code reference](../markdown-reference/code.md) for inline vs. fenced code, and [Footnotes](../markdown-reference/footnotes.md) for how footnote numbering works.
