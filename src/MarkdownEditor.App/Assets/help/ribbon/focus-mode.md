# Focus Mode

**`F11`** (or View tab → Focus Mode) hides the ribbon, the document tab strip, and the status bar, and centers the editor in a comfortable column for distraction-free writing.

A small **Exit Focus Mode** button appears in the top-right corner while it's active. To leave Focus Mode:

- Press **Esc**, or
- Press **F11** again, or
- Click the **Exit Focus Mode** button.

Whichever way you leave, your exact previous layout is restored — the same view mode (Split/Editor/Preview), the same Outline/Workspace panel state, and line numbers back on.

If the Find bar happens to be open when you enter Focus Mode, it's closed automatically, since it wouldn't have anywhere to go in the stripped-down layout.
