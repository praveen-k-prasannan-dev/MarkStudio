# Home Tab — Paragraph

| Control | Shortcut | Markdown produced |
|---------|----------|--------------------|
| Heading dropdown (Normal, H1–H6) | `Ctrl+1` … `Ctrl+6`, `Ctrl+0` for Normal | `#` … `######` |
| Bullet list | `Ctrl+Shift+8` | `- item` |
| Numbered list | `Ctrl+Shift+7` | `1. item` |
| Task list | `Ctrl+Shift+9` | `- [ ] item` |
| Blockquote | `Ctrl+Shift+Q` | `> quoted text` |

The heading dropdown reflects whatever heading level the line your caret is on already has — pick "Normal text" (or `Ctrl+0`) to clear a heading back to a plain paragraph.

Bullet, numbered, and task lists all toggle the same way formatting buttons do: apply again to remove the marker. See the full [Lists reference](../markdown-reference/lists.md) for nesting, sub-items, and how task-list checkboxes render.

> **Tip:** typing the word `todo`, `table`, `meeting`, or `code` and pressing `Tab` expands it into a ready-made structure automatically — see [Templates & Snippets](../templates-snippets.md).
