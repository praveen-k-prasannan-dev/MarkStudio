# Right-Click Context Menu

Right-click anywhere in the editor for a menu with:

- **Spelling** (only shown when you right-click a misspelled word) — up to five suggested corrections, plus **Add to Dictionary**. See [Spell Checking](spell-checking.md).
- **Cut**, **Copy**, **Paste**
- **Undo**, **Redo**
- **Bold**, **Italic**, **Insert Link…**
- **Table** submenu (only shown when your caret is inside a table) — the same Insert Row/Column and Delete Row/Column commands as the [Table tab](ribbon/table-tab.md).
- **Select All**

The Spelling and Table sections only appear when they're relevant, so the menu stays short the rest of the time.
