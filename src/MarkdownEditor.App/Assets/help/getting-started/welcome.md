# Welcome to MarkStudio Editor

MarkStudio Editor is a Windows Markdown document viewer and editor with a Word-style ribbon toolbox and a live preview — so you can write Markdown without needing to memorize Markdown syntax.

## The main window

The window is split into three areas:

- **Ribbon** across the top — click Bold, Headings, Lists, Table, etc. instead of typing Markdown syntax.
- **Editor** on the left — your Markdown source, with syntax highlighting.
- **Preview** on the right — a live, GitHub-style rendering of your document that updates as you type.

You can switch between Split, Editor-only, and Preview-only layouts from the **View** tab.
