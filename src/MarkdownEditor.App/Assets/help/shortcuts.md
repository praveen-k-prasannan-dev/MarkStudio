# Keyboard Shortcuts Reference

## File

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New document |
| `Ctrl+O` | Open… |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save As… |

## Formatting

| Shortcut | Action |
|----------|--------|
| `Ctrl+B` | Bold |
| `Ctrl+I` | Italic |
| `Ctrl+Shift+X` | Strikethrough |
| `Ctrl+Shift+C` | Inline code |
| `Ctrl+Shift+H` | Highlight |
| `Ctrl+1` … `Ctrl+6` | Heading 1–6 |
| `Ctrl+0` | Normal text (clear heading) |
| `Ctrl+Shift+8` | Bullet list |
| `Ctrl+Shift+7` | Numbered list |
| `Ctrl+Shift+9` | Task list |
| `Ctrl+Shift+Q` | Blockquote |

## Insert

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Insert link |
| `Ctrl+Shift+I` | Insert image |
| `Ctrl+Shift+K` | Insert code block |

## Editing & navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl+F` | Find |
| `Ctrl+H` | Replace |
| `F3` | Find next |
| `Shift+F3` | Find previous |
| `Ctrl+A` | Select all |
| `Tab` / `Shift+Tab` | Next/previous table cell (inside a table); expands a [snippet](templates-snippets.md) otherwise |

## App-level

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+P` | [Command Palette](command-palette.md) |
| `F11` | [Focus Mode](ribbon/focus-mode.md) |
| `F1` | This Help window |
| `Ctrl+P` | Print |
| `Esc` | Close Find bar / exit Focus Mode / close a popup or dialog |

Every shortcut here is also searchable by name in the [Command Palette](command-palette.md), which shows the shortcut next to each entry.
