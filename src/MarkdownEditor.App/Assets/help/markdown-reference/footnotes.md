# Footnotes

```
Here's a claim that needs a source.[^1]

[^1]: This is the footnote text.
```

Here's a claim that needs a source.[^1]

[^1]: This is the footnote text.

The reference (`[^1]`) can appear anywhere in the text; the definition (`[^1]: ...`) is usually placed at the bottom of the document. The ribbon's **Footnote** button ([Insert Tab — Blocks](../ribbon/insert-blocks.md)) inserts both halves for you and picks the next free number automatically.
