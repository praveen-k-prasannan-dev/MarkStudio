# Emphasis (Bold, Italic, Strikethrough, Highlight)

| Syntax | Renders as |
|--------|------------|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `***bold italic***` | ***bold italic*** |
| `~~strikethrough~~` | ~~strikethrough~~ |
| `==highlight==` | ==highlight== |
| `` `inline code` `` | `inline code` |

All six have ribbon buttons and keyboard shortcuts on [Home Tab — Font](../ribbon/home-font.md), and toggle on/off like Word.

You can combine them: `**bold with *nested italic* inside**` renders as **bold with *nested italic* inside**.
