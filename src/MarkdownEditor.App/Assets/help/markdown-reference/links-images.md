# Links & Images

## Links

```
[link text](https://example.com)
```

[link text](https://example.com)

A link to another local `.md` file (`[my notes](notes.md)`) opens that file in a new tab when clicked in the preview — see [Workspace Mode](../workspace-mode.md).

## Images

```
![alt text](path/to/image.png)
```

Use the ribbon's **Image** button (`Ctrl+Shift+I`), or drag an image file onto the window — either way, the path is made relative to your document automatically.

## Auto-links

A bare URL like `https://example.com` is automatically turned into a clickable link, without needing the `[text](url)` form.
