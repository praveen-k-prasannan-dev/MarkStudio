# Headings

Syntax:

```
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
```

Renders as:

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

Use the ribbon's Heading dropdown, `Ctrl+1`…`Ctrl+6`, or `Ctrl+0` to clear a heading back to a normal paragraph — see [Home Tab — Paragraph](../ribbon/home-paragraph.md). The [Outline panel](../ribbon/view-panels.md) builds its heading tree from these.
