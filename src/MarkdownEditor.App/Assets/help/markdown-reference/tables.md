## Column alignment

```
| Left | Center | Right |
| :--- | :---: | ---: |
| a | b | c |
```

| Left | Center | Right |
| :--- | :---: | ---: |
| a | b | c |

You almost never need to type the pipes and dashes by hand — use the ribbon's **Table** grid picker or **Insert Table…** dialog (see [Insert Tab — Tables](../ribbon/insert-tables.md)), and once your caret is inside a table, `Tab`/`Shift+Tab` move between cells and the [Table tab](../ribbon/table-tab.md) handles inserting/deleting rows and columns.
