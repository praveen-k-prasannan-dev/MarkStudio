```
> It can span multiple lines.
>

```

Ribbon button and shortcut on [Home Tab — Paragraph](../ribbon/home-paragraph.md) (`Ctrl+Shift+Q`). Blockquotes can nest (`>>`) and can contain other Markdown, including lists and code blocks.
