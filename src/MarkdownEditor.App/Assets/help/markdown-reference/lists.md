# Lists

## Bullet lists

```
- First item
- Second item
  - Nested item
- Third item
```

- First item
- Second item
  - Nested item
- Third item

## Numbered lists

```
1. First step
2. Second step
3. Third step
```

1. First step
2. Second step
3. Third step

## Task lists

```
- [ ] Not done yet
- [x] Already done
```

- [ ] Not done yet
- [x] Already done

Click a task's checkbox in the **preview pane** to toggle it. All three list types have ribbon buttons and shortcuts on [Home Tab — Paragraph](../ribbon/home-paragraph.md), and `todo`+`Tab` is a quick shortcut for a single task item — see [Templates & Snippets](../templates-snippets.md).

Indent a line with two extra spaces to nest it under the item above.
