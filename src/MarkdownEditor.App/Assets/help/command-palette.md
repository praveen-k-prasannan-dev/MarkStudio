# Command Palette

**`Ctrl+Shift+P`** opens a VS Code-style overlay: a single search box over a live-filtered list of nearly every command in the app — every ribbon button, every menu item, view toggles, export commands, and more.

- Type a few letters and the list narrows instantly using **fuzzy matching** — the letters just need to appear in order, not consecutively. Typing "list" finds Bullet List, Numbered List, and Task List; typing "pdf" finds Export to PDF.
- Use **↑ / ↓** to move the selection, **Enter** to run the highlighted command, **Esc** to close without doing anything.
- Click a result with the mouse to run it directly.
- When your caret is inside a table, the palette also lists the row/column commands (Insert Row Above, Delete Column, etc.) — the same ones on the [Table tab](ribbon/table-tab.md).

This is usually the fastest way to reach something once you know roughly what it's called, without hunting through ribbon tabs.
