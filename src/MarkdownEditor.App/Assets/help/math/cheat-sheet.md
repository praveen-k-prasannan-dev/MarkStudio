# Math Cheat Sheet

Every symbol from the [Basics](basics.md), [Greek Letters & Functions](greek-functions.md), [Sums/Products/Integrals & Limits](calculus.md), [Matrices & Vectors](matrices.md), and [Sets, Logic & Relations](sets-logic.md) pages, in one scannable table.

| Category | Symbol | LaTeX |
|----------|--------|-------|
| Arithmetic | $a \times b$ | `\times` |
| Arithmetic | $a \div b$ | `\div` |
| Arithmetic | $\pm$ | `\pm` |
| Fraction | $\frac{a}{b}$ | `\frac{a}{b}` |
| Exponent | $x^2$ | `x^2` |
| Subscript | $x_1$ | `x_1` |
| Root | $\sqrt{x}$ | `\sqrt{x}` |
| Root | $\sqrt[n]{x}$ | `\sqrt[n]{x}` |
| Sum | $\sum_{i=1}^{n}$ | `\sum_{i=1}^{n}` |
| Product | $\prod_{i=1}^{n}$ | `\prod_{i=1}^{n}` |
| Integral | $\int_a^b$ | `\int_a^b` |
| Double integral | $\iint$ | `\iint` |
| Limit | $\lim_{x \to 0}$ | `\lim_{x \to 0}` |
| Derivative | $\frac{d}{dx}$ | `\frac{d}{dx}` |
| Partial derivative | $\frac{\partial f}{\partial x}$ | `\frac{\partial f}{\partial x}` |
| Infinity | $\infty$ | `\infty` |
| Greek (lower) | $\alpha \beta \gamma \delta \theta \lambda \mu \pi \sigma \phi \omega$ | `\alpha`, `\beta`, `\gamma`, `\delta`, `\theta`, `\lambda`, `\mu`, `\pi`, `\sigma`, `\phi`, `\omega` |
| Greek (upper) | $\Gamma \Delta \Theta \Lambda \Sigma \Phi \Omega$ | `\Gamma`, `\Delta`, `\Theta`, `\Lambda`, `\Sigma`, `\Phi`, `\Omega` |
| Trig | $\sin \cos \tan$ | `\sin`, `\cos`, `\tan` |
| Log | $\log$, $\ln$ | `\log`, `\ln` |
| Set membership | $\in$, $\notin$ | `\in`, `\notin` |
| Subset | $\subset$, $\subseteq$ | `\subset`, `\subseteq` |
| Union / intersection | $\cup$, $\cap$ | `\cup`, `\cap` |
| Empty set | $\emptyset$ | `\emptyset` |
| Number sets | $\mathbb{N}\mathbb{Z}\mathbb{Q}\mathbb{R}\mathbb{C}$ | `\mathbb{N}`, `\mathbb{Z}`, `\mathbb{Q}`, `\mathbb{R}`, `\mathbb{C}` |
| For all / exists | $\forall$, $\exists$ | `\forall`, `\exists` |
| Not | $\neg$ | `\neg` |
| And / or | $\land$, $\lor$ | `\land`, `\lor` |
| Implies | $\implies$, $\iff$ | `\implies`, `\iff` |
| Comparison | $\le \ge \ne \approx \equiv$ | `\le`, `\ge`, `\ne`, `\approx`, `\equiv` |
| Arrows | $\rightarrow \Rightarrow \leftrightarrow$ | `\rightarrow`, `\Rightarrow`, `\leftrightarrow` |
| Vector | $\vec{v}$ | `\vec{v}` |
| Matrix (parens) | $\begin{pmatrix}a&b\\c&d\end{pmatrix}$ | `\begin{pmatrix}...\end{pmatrix}` |
| Matrix (brackets) | $\begin{bmatrix}a&b\\c&d\end{bmatrix}$ | `\begin{bmatrix}...\end{bmatrix}` |
| Auto brackets | $\left(\frac{a}{b}\right)$ | `\left(...\right)` |

Remember: **inline** math is `$...$` on the same line as text; **block** math needs `$$` on its own line before and after the formula.
