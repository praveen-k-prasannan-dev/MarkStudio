# Sets, Logic & Relations

## Set theory

| Syntax | Renders as |
|--------|------------|
| `$x \in A$` | $x \in A$ |
| `$x \notin A$` | $x \notin A$ |
| `$A \subset B$` | $A \subset B$ |
| `$A \subseteq B$` | $A \subseteq B$ |
| `$A \cup B$` (union) | $A \cup B$ |
| `$A \cap B$` (intersection) | $A \cap B$ |
| `$A \setminus B$` (set difference) | $A \setminus B$ |
| `$\emptyset$` | $\emptyset$ |
| `$\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{C}$` | $\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{C}$ |

## Logic

| Syntax | Renders as |
|--------|------------|
| `$\forall x$` (for all) | $\forall x$ |
| `$\exists x$` (there exists) | $\exists x$ |
| `$\nexists x$` | $\nexists x$ |
| `$\neg p$` (not) | $\neg p$ |
| `$p \land q$` (and) | $p \land q$ |
| `$p \lor q$` (or) | $p \lor q$ |
| `$p \implies q$` | $p \implies q$ |
| `$p \iff q$` | $p \iff q$ |
| `$\therefore$` | $\therefore$ |
| `$\because$` | $\because$ |

## Relations & comparison

| Syntax | Renders as |
|--------|------------|
| `$a \le b$`, `$a \ge b$` | $a \le b$, $a \ge b$ |
| `$a \ne b$` | $a \ne b$ |
| `$a \approx b$` | $a \approx b$ |
| `$a \equiv b$` | $a \equiv b$ |
| `$a \propto b$` | $a \propto b$ |
| `$a \gg b$`, `$a \ll b$` | $a \gg b$, $a \ll b$ |
