# Math Basics

## Arithmetic & grouping

| Syntax | Renders as |
|--------|------------|
| `$a + b - c$` | $a + b - c$ |
| `$a \times b$` or `$a \cdot b$` | $a \times b$ |
| `$a \div b$` | $a \div b$ |
| `$\pm$` / `$\mp$` | $\pm$ / $\mp$ |
| `$(a+b)$` | $(a+b)$ |
| `$\left(\frac{a}{b}\right)$` | $\left(\frac{a}{b}\right)$ — auto-sized brackets |

## Fractions

| Syntax | Renders as |
|--------|------------|
| `$\frac{a}{b}$` | $\frac{a}{b}$ |
| `$\frac{1}{2} + \frac{1}{3}$` | $\frac{1}{2} + \frac{1}{3}$ |
| `$\dfrac{a}{b}$` | larger "display style" fraction, for inline use |

## Exponents & subscripts

| Syntax | Renders as |
|--------|------------|
| `$x^2$` | $x^2$ |
| `$x^{10}$` (braces for multi-character) | $x^{10}$ |
| `$x_1$` | $x_1$ |
| `$x_{i,j}$` | $x_{i,j}$ |
| `$x_i^2$` | $x_i^2$ |
| `$e^{-x^2}$` | $e^{-x^2}$ |

## Roots

| Syntax | Renders as |
|--------|------------|
| `$\sqrt{x}$` | $\sqrt{x}$ |
| `$\sqrt{a^2+b^2}$` | $\sqrt{a^2+b^2}$ |
| `$\sqrt[3]{x}$` (cube root) | $\sqrt[3]{x}$ |
| `$\sqrt[n]{x}$` (nth root) | $\sqrt[n]{x}$ |

## A worked example

```
$$
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$
```

$$
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$
