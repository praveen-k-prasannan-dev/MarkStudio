## Named functions

MathJax renders these upright (not italic), the way they're conventionally typeset:

| Syntax | Renders as |
|--------|------------|
| `$\sin x$`, `$\cos x$`, `$\tan x$` | $\sin x$, $\cos x$, $\tan x$ |
| `$\sec x$`, `$\csc x$`, `$\cot x$` | $\sec x$, $\csc x$, $\cot x$ |
| `$\arcsin x$`, `$\arccos x$`, `$\arctan x$` | $\arcsin x$, $\arccos x$, $\arctan x$ |
| `$\sinh x$`, `$\cosh x$`, `$\tanh x$` | $\sinh x$, $\cosh x$, $\tanh x$ |
| `$\log x$`, `$\ln x$`, `$\log_2 x$` | $\log x$, $\ln x$, $\log_2 x$ |
| `$\exp(x)$` | $\exp(x)$ |
| `$\min(a,b)$`, `$\max(a,b)$` | $\min(a,b)$, $\max(a,b)$ |
| `$\gcd(a,b)$` | $\gcd(a,b)$ |
